# 首页模式

## 纸片模式

纸片模式按置顶状态和更新时间排序，支持全部、待办、笔记和未完成筛选。折叠纸片显示在底部胶囊栏，点击纸片进入 `TodoPaperView` 或 `NotePaperView`。

## 今日模式

今日模式是默认首页，聚合当天的未完成待办、已安排任务和日历事件，显示完成进度、已安排时长和未安排任务数量，并提供快速记录和今日回顾入口。点击已安排任务可直接完成，长按可调整时间。快速记录将任务保存到“收件箱”纸片，将笔记创建为新的笔记纸片。

## 日历模式

日历模式顶部提供日历上下文工具栏，显示当前月份、选中日期、日程数量，并提供今天定位、前后月份切换和快速新增日程。内容区域由月历卡和日时间线组成。月份网格按系统 `firstWeekday` 排列，日期单元格使用最多四个事件分类色点和溢出数量保持稳定高度。事件按开始日期和结束日期覆盖范围显示在每个相关日期；时间线会为跨日事件显示延续边界，并显示当前时间和日程完成进度。事件分类为个人、工作、杂事、重要、休闲、日常、购物和出行，并使用分类背景、文字色和圆环色。时间线事件支持通过上下文菜单直接切换完成状态。

## 四象限模式

四象限根据 `TodoItem.quadrant` 展示任务。旧任务在没有持久化象限时，按照文本中的“紧急”“今天”“马上”“重要”“项目”“截止”等关键词派生默认象限。用户可以移动任务、编辑文本、标记完成或打开所属待办纸片。

## 状态保持

首页模式、配色、外观、待办字号、自动清除和 Markdown 渲染强度由 `AppSettings` 写入 `UserDefaults`。纸片和待办内容由共享 SwiftData 容器持久化。

## 笔记任务联动

笔记中的 `- [ ] 任务文本` 可通过笔记工具栏导入“收件箱”纸片。导入过程按任务文本去重，原 Markdown 正文保持不变。
